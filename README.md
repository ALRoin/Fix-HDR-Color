# KernelSu Module
## Fix HDR Color by automatically disabling HW overlays

### There are two choices:
  1. Always disable HW overlays when a target app is in the foreground.
  2. Only disable HW overlays when HDR video is playing in a selected target app (**Recommended**).

You can choose the mode during the installation process or through the Action button.

#### Add apps that play HDR videos to the target app list through the WebUI.

#### You can customize how often the script checks for changes in the WebUI.

> ⚠️ **IMPORTANT:** This module has only been tested on the Xiaomi Mi 9 running crDroid 12. Don't expect it to work the same way on other devices or ROMs.
